# Question 2 - Research Report Agent

## Objective

Build an agent that accepts a research topic, searches for relevant information from online sources, summarizes the findings, and generates a structured research report.

## Features

- Accepts a research topic from the user
- Searches online information using Wikipedia
- Retrieves multiple relevant sources
- Displays search results
- Generates a summary of the collected information
- Creates a structured research report
- Saves the report as `research_report.txt`

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Wikipedia API
