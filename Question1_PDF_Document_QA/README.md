# Question 1 - PDF Document Q&A

This project builds an AI agent that reads a PDF document, extracts relevant content, and answers user queries using an LLM.

## Technologies Used

- Python
- PyPDF
- LangChain
- OpenAI
- Retrieval-Augmented Generation (RAG)

## Project Structure

- `app.py` - Main application
- `make_pdf.py` - Creates the sample PDF
- `documents/` - Contains the PDF document

## Objective

To build a document question-answering agent that can retrieve relevant information from a PDF and provide accurate answers to user questions.
